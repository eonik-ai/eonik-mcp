# Contributing

eonik is a Mac app for making ads. This repo is the public connector so Claude, Cursor, and Codex can read that account.

Issues and pull requests are welcome for:

- Docs and install instructions
- Connector bugs (auth, catalog loading, dispatch errors)
- Translations under `docs/readme/`

Please do not add tools that pause, scale, kill, or launch ads. That is out of scope forever.

Use [connect@eonik.ai](mailto:connect@eonik.ai) for security reports ([SECURITY.md](SECURITY.md)).
