eonik は**広告をつくる Mac アプリ**です。このリポジトリは Claude、Cursor、Codex をアカウントにつなぎます。アシスタントはブランド・調査・数字を読み、下書きします。**支出はしません。カットの承認はあなたです。**

```json
{
  "mcpServers": {
    "eonik": {
      "command": "npx",
      "args": ["-y", "eonik-mcp"],
      "env": { "EONIK_API_KEY": "eonk_live_..." }
    }
  }
}
```

[Mac 版をダウンロード](https://www.eonik.ai/download) · エディタ無料 · macOS 15+ · Apple silicon
